\doxysubsubsection{Detailed Description}
Basic vector and matrix computations. 

This file contains routines for operating on 3-\/dimensional vectors and 3-\/by-\/3 matrices. It\textquotesingle{}s focused mostly on speed, and as such, is incredibly small.
