Performs a simulation using the given initial conditions.

Runs the simulation based on the initial conditions and calculation parameters. Outputs to a file and produces both the filepath and the parent folder filepath.

Parameters
[in]initial_stateThe initial state of the system.
[in]dc_optsThe derivative computation options.
[in]int_optsThe integral computation options.
[out]output_filenameThe output filename buffer for the dataset.
[out]output_folder_nameThe output folder buffer.
[in]output_filename_sizeThe size of the output filename buffer.
[in]otuput_folder_sizeThe size of the output folder buffer.
[in]print_file_outputWhether to print the output filename.
Returns
The error code for the simulation.
