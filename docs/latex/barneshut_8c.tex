\doxysubsubsection{Detailed Description}
External velocity contribution calculation through Barnes-\/\+Hut. 

This file contains an implementation of the Barnes-\/\+Hut algorithm for external velocity contribution using linear octrees as a backend.

\doxyparagraph{\texorpdfstring{MORTON\_BITS}{MORTON\_BITS}}
{\footnotesize\ttfamily \#define MORTON\+\_\+\+BITS~21}



The number of bits for storing morton codes (and subsequently, the maximum number of levels for the octree). 

In essence, there are floor( 64 bits / 3 axes ) = 21 bits available to each dimension (x, y, and z) using 64-\/bit integers, allowing our tree to have up to 21 levels (for a theoretical maximum of 9.\+2\+E18 nodes in the tree).
